# 行情阶段量化识别方案

## 一、问题定义

将价格走势划分为三种状态：
- **下跌阶段**：价格持续向下运动
- **震荡阶段**：价格在一定区间内来回波动，无明显方向
- **上涨阶段**：价格持续向上运动

---

## 二、候选方案概览

| 方案 | 核心思路 | 优点 | 缺点 |
|------|----------|------|------|
| 方案A：均线斜率法 | 用均线斜率判断趋势方向，斜率绝对值小则为震荡 | 简单直观 | 滞后性强，参数敏感 |
| 方案B：ADX指标法 | ADX衡量趋势强度，结合+DI/-DI判断方向 | 成熟经典 | 震荡判断依赖阈值 |
| 方案C：布林带宽度法 | 带宽窄→震荡，带宽扩张+方向→趋势 | 自适应波动率 | 假突破问题 |
| 方案D：线性回归斜率+R²法 | 拟合N日价格，斜率定方向，R²定趋势强度 | 统计严谨 | 计算稍复杂 |
| 方案E：HMM隐马尔可夫模型 | 将三阶段建模为隐藏状态，用收益率序列训练 | 自适应，无硬阈值 | 需训练，可解释性差 |

---

## 三、各方案详细说明

### 方案A：均线斜率法

**核心逻辑：**
- 计算 N 日均线（如 MA20）的斜率（当日MA与N日前MA之差/N）
- 斜率 > 阈值 θ₊ → 上涨阶段
- 斜率 < -θ₋ → 下跌阶段
- -θ₋ ≤ 斜率 ≤ θ₊ → 震荡阶段

**关键参数：** 均线周期 N，斜率阈值 θ

**适用场景：** 快速原型，趋势明显的品种

---

### 方案B：ADX 指标法（推荐首选）

**核心逻辑：**
- ADX（平均趋向指数）衡量趋势强弱，不含方向
- +DI / -DI 衡量上升/下降动能方向
- 判断规则：
  - ADX < 25 → 震荡阶段
  - ADX ≥ 25 且 +DI > -DI → 上涨阶段
  - ADX ≥ 25 且 +DI < -DI → 下跌阶段

**优点：** 经典成熟，广泛验证，无需训练

**关键参数：** ADX周期（通常14），强度阈值（通常25）

---

### 方案C：布林带宽度法

**核心逻辑：**
- 布林带宽度 BW = (上轨 - 下轨) / 中轨
- BW 相对历史分位数低 → 震荡（挤压状态）
- BW 扩张 + 价格突破上轨 → 上涨阶段
- BW 扩张 + 价格跌破下轨 → 下跌阶段

**优点：** 波动率自适应，能预警趋势启动

**适用场景：** 配合其他指标使用

---

### 方案D：线性回归斜率 + R² 法（统计最严谨）

**核心逻辑：**
- 对过去 N 根 K 线的收盘价做线性回归
- 斜率 β 反映趋势方向与速度
- 决定系数 R² 反映拟合优度（趋势纯度）
- 判断规则：
  - R² < τ（如 0.3）→ 震荡阶段（价格不沿直线运动）
  - R² ≥ τ 且 β > 0 → 上涨阶段
  - R² ≥ τ 且 β < 0 → 下跌阶段

**优点：** 斜率和方向同时被量化，震荡判断有统计依据

**关键参数：** 回归窗口 N，R² 阈值 τ，斜率标准化处理

---

### 方案E：HMM 隐马尔可夫模型

**核心逻辑：**
- 定义 3 个隐藏状态：上涨/震荡/下跌
- 观测变量：日收益率、波动率等
- 用 EM 算法（Baum-Welch）训练转移矩阵与发射概率
- 用 Viterbi 算法解码历史状态序列

**优点：** 无需硬性阈值，自动学习状态转换规律

**缺点：** 需大量历史数据训练；状态含义需事后标注；实时推理有延迟

**适用场景：** 研究分析，不适合实盘实时信号

---

## 四、推荐实施路径

```
第一步（基准）：  ADX 法快速实现，验证三段划分效果
第二步（优化）：  线性回归斜率+R² 法对比，找出漏判/误判案例
第三步（进阶）：  HMM 作为研究工具，评估前两者的边界准确性
```

---

## 五、评估方式

1. **视觉校验**：将识别结果染色标注在 K 线图上，与肉眼判断对比
2. **状态持续性**：合理的阶段应有最小持续时长，避免频繁切换（需加平滑/最小持续N日过滤）
3. **切换点准确性**：对比已知历史顶底区间，计算识别延迟
