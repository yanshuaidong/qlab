# Plan 4：主力共振 + 积累质量 · LightGBM 增强组合策略

**前置研究**：[Plan 1](../plan1/docs/report.md) · [Plan 2](../plan2/docs/report.md) · [Plan 3](../plan3/docs/report.md)  
**数据**：`fut_strength`（`main_force` / `retail`）+ `fut_daily_close`  
**实现**：`scripts/common.py` · `scripts/train_lgbm.py` · `scripts/backtest_plan4.py`

---

## 0. 设计目标

在前三轮研究已验证的事实上，把「规则策略」升级为「规则触发 + 机器学习排序/过滤」：

| 来源 | 已验证结论 | Plan 4 用法 |
|------|-----------|------------|
| Plan 1 | 主力与价格同向 ~66%，散户反向；主散对立 ~77% | 共振/对立特征；品种池门槛 |
| Plan 2 | 严格 7 日开仓 + 3 日主力拐头离场；A 通道有效；3 槽 + 板块互斥提升质量 | **交易骨架不变** |
| Plan 3 | 连续单向积累时方向准确率 ~73%；`|cumulative_delta|` 越大价格变动越大 | **Run 质量特征**；训练标签与仓位权重 |

**Plan 4 只做两件事**（不改动 Plan 2 开平仓规则）：

1. 用 LightGBM 在「严格 7 日信号日」预测该笔交易是否盈利（二分类）。
2. 组合层用模型概率 `lgb_prob` 替代纯 `main_score` 分位排序，并设概率下限过滤弱信号。

---

## 1. 品种池（沿用 Plan 2）

12 品种、6 板块、全部 A 通道（主力驱动，`retail` 仅确认）：

沪铜、沪铝、沪锌、沪金、铁矿石、焦煤、PTA、甲醇、橡胶、豆粕、棕榈油、玉米。

入池逻辑（Plan 1）：`main~close` 显著 + `main~retail` 反向 ≥ 70%，按板块配额抽样，**不按历史同向率排名机械选品**。

---

## 2. 交易规则（与 Plan 2 完全一致）

### 2.1 开仓 · 严格 7 日（5+3 重合）

- **多**：5 日 `main_force` 均 < 0 且第 5 日为极小值；随后 3 日 `main_force` 连升且 `retail` 连降。  
- **空**：对称（5 日均 > 0 极大值；3 日主力连降、散户连升）。

### 2.2 平仓 · 3 日主力拐头

- 多：`main_force(t) - main_force(t-2) < 0` → 当日收盘平多。  
- 空：`main_force(t) - main_force(t-2) > 0` → 当日收盘平空。

### 2.3 组合约束

- 最多 **3** 槽；**板块互斥**；每槽 1/3 权重；空槽现金。  
- 平仓当日不反手；同日释放槽位不接同日新信号。

---

## 3. LightGBM 建模

### 3.1 样本定义

- **一条样本 = 一次严格 7 日开仓**（多或空），特征取 **信号日收盘后** 的状态。  
- **标签 `y`**：该笔按 Plan 2 规则持有至 tp3 离场（或样本末强平）后，`pnl_ratio > 0` → 1，否则 0。

### 3.2 特征（信号日）

| 组别 | 特征 | 含义 |
|------|------|------|
| Plan 2 基线 | `main_force`, `retail`, `m3`, `main_score` | 动量与分位 |
| Plan 1 共振 | `res_main_close_3`, `res_retail_close_opp_3`, `res_main_retail_opp_3` | 近 3 日滑窗同向/反向占比 |
| Plan 3 积累 | `z_main`, `diff2`, `run_streak`, `cum_z_5`, `cum_z_10` | z-score、连续单调、累积变化 |
| 结构 | `main_minus_retail`, `side`（1/-1） | 主散差、方向 |

### 3.3 训练设置

- 算法：`lightgbm.LGBMClassifier`（class_weight=balanced）。  
- 划分：按时间 **前 70% 交易日训练 / 后 30% 验证**（避免随机打乱泄漏）。  
- 输出：`artifacts/models/lgbm_entry.pkl`、`feature_meta.json`、`metrics.json`。

### 3.4 组合层使用方式

对每个候选开仓信号：

1. 计算特征 → `lgb_prob = P(y=1)`。  
2. 若 `lgb_prob < MIN_PROB`（默认 **0.52**）→ **丢弃**（不进候选池）。  
3. 其余候选按 `lgb_prob` 降序选满空槽（仍遵守板块互斥）。

**样本内（前 70%）**：无模型或回退 `main_score` 排序，用于对照。  
**样本外（后 30%）**：启用 LightGBM 过滤 + 排序，主回测指标以此为准。

## 5. 预期与风险

- **预期**：Plan 3 表明「高质量积累」对应更大波动；模型应学会在规则信号日上区分高/低质量 run，减少 Plan 2 中 0 胜率拖累品种（如部分农产品）的无效开仓。  
- **风险**：180 日样本偏短；标签与特征同源（主力序列）易过拟合 → 必须看 **OOS 段** AUC/胜率，不以全样本拟合为准。  
- **不做**：改 7 日/3 日窗长、加 B 通道、加硬止损（与 Plan 2 设计一致）。

## 6. 运行方式

```bash
cd research/futures/plan4

# macOS 若 LightGBM 报 libomp 缺失：
# brew install libomp

# 1. 训练（优先 LightGBM，失败则回退 sklearn HistGradientBoosting）
python scripts/train_lgbm.py

# 2. 组合回测 + 报告
python scripts/backtest_plan4.py
```

交付物：

- `artifacts/models/` — 模型与指标  
- `artifacts/data/` — 训练样本、回测汇总、交易明细  
- `docs/report.md` — 自动生成回测报告
