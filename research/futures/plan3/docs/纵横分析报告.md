# 主力持续单向积累：从方向验证到趋势质量量化

## 一、一句话定义

**主力持续单向积累**是一种基于日大单委托统计的期货趋势预测方法：将主力资金的 z-score 标准化指数在 2 日差分维度上识别连续单调运动区间，以该区间的累积变化幅度（cumulative_delta）预测同期期货价格变动的方向与大小。

---

## 二、纵向分析：从"方向对吗"到"力度有多大"

### 2.1 起源：一组指标和一个疑问

这项研究的起点，是一组存储在本地 SQLite 数据库里的字段。

`main_force`。`retail`。`close_price`。

三个字段，每天每个品种各一行，覆盖全市场 55 个期货品种、180 个交易日。main_force 基于大单委托统计——正值意味着大单做多活跃，负值意味着大单做空活跃。retail 基于散单委托，含义对称。close_price 就是当日期货收盘价。

拿到这组数据的时候，问题很朴素：**主力资金的动向，和期货价格的涨跌，到底有没有关系？**

这不是一个新鲜的疑问。在量化交易领域，"主力资金流向"作为alpha因子已经被研究了二十多年。从早期的筹码分布理论，到后来的Level-2逐笔委托分析，再到如今基于机器学习的订单流拆解，"跟踪大资金"几乎是每个量化团队的必修课。但理论研究是一回事，具体到某个品种、某段时间、某种数据源，关系是否成立，谁也说不准。

所以第一步，只能是验证。

### 2.2 Plan 1：证明了"主力在跟价格走"，但不够

Plan 1 的设计很直接。用固定长度的滑动窗口（S=2,3,4），在每个窗口内计算主力指数的首尾差分——Δ > 0 标记为"涨"，Δ < 0 标记为"跌"。然后统计这些方向标记与同期收盘价方向标记一致的比例。

结果出来了：S=3 时，全市场平均同向率 63.9%，中位数 66.1%。45 个品种通过"同向率 ≥ 55% 且二项检验 p < 0.05"的门槛。

散户那边更惊人：反向率 64.4%，中位数 66.7%。主力做多的时候散户在做空，主力做空的时候散户在接盘。两个假设同步成立。

Bootstrap 置乱检验（2000 次）把统计偶然性排除了——零假设下的同向率均值约 49.5%，而实测中位数 66%，两者相差 16 个百分点。这不是巧合。

但 Plan 1 的结论是**定性**的。它回答的是：主力方向和价格方向是否一致？答案是"是"。但它回答不了：

- 一致的时候，价格会涨多少？
- 不一致的时候，是主力错了还是价格滞后？
- 主力"轻轻地"做多和"狠狠地"做多，结果一样吗？

更重要的是，Plan 1 的方法论有一个结构性缺陷：**固定滑窗是被动的时间切片**。

不管市场实际状态如何，每 3 天切一刀。这刀可能切在趋势中段，也可能切在震荡区间。切在趋势中段的时候，主力方向和价格方向当然一致；切在震荡区间的时候，两者可能完全无关，但被一视同仁地计入了统计。这就好比用一把尺子去量一堆形状各异的石头——量出来的"平均长度"有意义，但每块石头的真实轮廓被抹平了。

### 2.3 固定滑窗的盲区：三天一切，切出了噪音

想象一个场景。

某品种的主力指数在 5 个交易日内经历了这样的变化：+0.5, -0.3, +0.8, +0.2, -0.4。用 S=3 的滑窗去切，会得到两个窗口：

- 窗口 1（第1-3天）：主力从 +0.5 到 +0.8，方向为涨；假设收盘价也是从 100 涨到 103，方向为涨。同向，计入"成功"。
- 窗口 2（第3-5天）：主力从 +0.8 到 -0.4，方向为跌；假设收盘价从 103 跌到 101，方向为跌。同向，也计入"成功"。

两个窗口都"成功"了。但如果仔细看，这 5 天的主力走势根本不是单向的——它先涨后跌再涨再跌，像一个醉汉在走路。Plan 1 的滑窗把这段"醉汉走路"切成了两段"直线"，每段看起来都很完美，但合起来完全不是那回事。

这就是固定滑窗的核心问题：**它假设时间可以被任意切片，但市场的运动是有结构的。** 趋势的起点和终点不是人为设定的，而是由价格本身的运动决定的。

用户意识到了这一点。他说："主力指数从 -30 运动到了 +30，期间用了 20 个交易日，期货价格上涨了 10%。但如果是从 -10 到 +10 只用了 3 天，价格变化就小得多。"

这里的关键词不是"-30 到 +30"，而是"20 个交易日"。**持续时间。积累幅度。** 这才是驱动价格变动的真正力量。

### 2.4 走向 Plan 3：一个例子引发的追问

从 Plan 1 到 Plan 3，转折点是这个追问：

> "主力指数持续单向运动的时间越长、积累的幅度越大，期货价格的变动就越大。"

这不是 Plan 1 的延续，而是一个全新的维度。Plan 1 问的是"方向是否一致"，Plan 3 问的是"积累的质量如何转化为价格变动的大小"。从定性到定量，从方向到幅度，从被动切片到主动识别。

但这个问题的精确表述并不容易。什么叫"持续单向运动"？持续多久算持续？幅度多大算大？用什么指标衡量"质量"？

用户给出了一个关键的约束条件：**"越复合越不准"**。这意味着不能堆砌多个指标做一个花哨的复合质量分数，而要找到一个最简单、最直接、最不容易过拟合的度量。

最终选定的指标是 `cumulative_delta`：run 期间 z-score 的净变化量。从 run 开始时的 z-score 到 run 结束时的 z-score，差值就是积累的质量。

为什么是 z-score？因为主力指数的绝对值在不同品种之间不可比。螺纹钢的主力指数可能是 50，沪金的可能是 5000，但两者的"力量"不一定差 100 倍。z-score 把每个品种的主力指数拉回到同一个尺度上——均值为 0，标准差为 1。这样，+2 在螺纹钢和 +2 在沪金代表的含义是一致的：都意味着主力力量显著高于该品种的历史平均水平。

为什么是 2 日差分（t - (t-2)）？因为 1 日差分太敏感，日间噪音太多。2 日差分相当于给数据做了一层平滑，过滤掉了单日的大幅波动，只保留持续的趋势信号。

为什么是 duration ≥ 3？因为太短的运动（1-2 天）可能只是随机扰动，不值得认真对待。

这些选择都不是最优解——它们是在"简单"和"有效"之间的平衡。

### 2.5 方法论重构：从被动切片到主动识别

Plan 3 的方法论可以概括为四个步骤：

**标准化**：对每个品种的主力指数做 z-score 标准化，使品种间可比。

**差分**：计算 diff2[t] = z_score[t] - z_score[t-2]，标记每 2 天的趋势方向（+1 为增，-1 为减，0 为持平）。

**识别**：扫描 diff2 序列，把连续相同符号的片段合并为一个"run"（连续单调区间）。过滤掉 duration ≤ 2 的短 run。

**度量**：对每个 run，计算 cumulative_delta（z-score 净变化）和同期 price_change%（价格变化率）。

这一步把 Plan 1 的"每 3 天切一刀"变成了"让数据自己决定切在哪里"。run 的长度不固定——有的 3 天，有的 21 天，平均 6.26 天。这意味着模型在"倾听"数据的声音，而不是强行把数据塞进预设的框架。

从全市场 55 个品种、180 个交易日中，一共识别出了 1,452 个 runs。717 个做多 run，735 个做空 run。数量大致均衡，没有明显的多空偏差。

### 2.6 关键决策：为什么选择 t-(t-2)

这里有一个值得展开的技术细节。

用户最初的表述是："(t) - (t-2) 的大小一直是正或负"。这意味着他关注的是 2 日差分的符号一致性，而不是 1 日差分。

为什么不直接用 1 日差分？

因为期货市场的日间噪音太大了。一个品种在某一天可能因为某个宏观消息、某个交割日效应、或者某个大户的单笔异常委托，导致主力指数突然跳动。如果用 1 日差分，这种跳动会被误判为趋势反转，从而产生大量虚假的 run 切换。

2 日差分相当于要求趋势至少持续两个交易日才被认为是"真实的"。这是一个经验性的过滤门槛，不是理论上推导出来的最优值。但它有效——在 180 个交易日的数据中，每个品种平均识别出约 26 个 runs，这意味着大约 6-7 天出现一个趋势切换点。这个频率与市场经验大致吻合。

另一个关键决策是**不做复合指标**。

用户明确要求："累计 z-score 变化总量就够用了，越复合越不准。"

这句话背后的逻辑很深刻。复合指标（比如 duration × avg(|diff2|)）看起来考虑了更多维度，但实际上引入了额外的参数和假设。duration 和 avg(|diff2|) 可能高度相关——长得久的 run 往往 diff2 也大——复合指标会把这种相关性放大，导致过拟合。cumulative_delta 只有一个维度：z-score 从起点到终点的净变化。简单，透明，不容易被数据中的偶然模式欺骗。

### 2.7 Plan 3 的结果：验证了什么，留下了什么

Plan 3 的结果可以从三个层面来看。

**方向层面**：整体方向准确率 72.66%。做多 run 中 73.36% 的价格确实上涨，做空 run 中 71.97% 的价格确实下跌。

这个数字比 Plan 1 的 66% 高出了 6.7 个百分点。表面看只是小幅提升，但背后的含义完全不同。Plan 1 的 66% 是"所有时间窗口的平均"，包含了大量震荡和噪音；Plan 3 的 72.66% 是"筛选后的趋势区间的平均"。换句话说，当你把注意力集中在"主力真正在做事"的那些时间段时，预测的准确率从"勉强可用"跃升到了"相当可靠"。

**幅度层面**：这是 Plan 3 的核心发现。把所有 runs 按 |cumulative_delta| 分为三等分：

- 低质量组（底部 1/3）：平均 |price_change%| = 2.45%
- 中质量组（中间 1/3）：平均 |price_change%| = 3.30%
- 高质量组（顶部 1/3）：平均 |price_change%| = 5.10%

三组单调递增。高质量组的价格变动幅度是低质量组的 2.08 倍。

这意味着：**主力积累的质量越高，推动的价格变动就越大。** 用户的假设被数据强力支持。

**统计层面**：|price_change%| ~ |cumulative_delta| 的线性回归，斜率 = 0.0126，p = 8.50×10⁻²⁰，R² = 0.0556。

p 值极显著，说明关系确实存在。但 R² 只有 5.56%，意味着 |cumulative_delta| 只能解释约 5.6% 的价格变动方差。剩下的 94.4% 由什么解释？宏观事件、政策变化、国际市场联动、散户情绪、技术面突破……期货市场是一个复杂的系统，单一因子不可能解释一切。

但这个 5.56% 不应该被低估。在量化因子研究中，一个单因子的 R² 能达到 5% 已经属于"可用"级别。更重要的是，这个因子的逻辑非常清晰——它不是某种神秘的统计套利，而是有明确经济含义的：大资金的持续单向积累会推动价格向该方向运动。

多空拆分后还有额外发现：做多 runs 的回归斜率（0.0155）显著大于做空 runs（0.0091）。这意味着，同样幅度的主力持续积累，对价格上涨的推动力大于对价格下跌的推动力。这可能与期货市场的一些结构性特征有关——比如多头持有成本（资金成本、仓储成本）使得多头入场更为"慎重"，一旦决定持续做多，往往意味着更强的 conviction。

## 三、横向分析：谁信号强，谁信号弱

### 3.1 品种全景：55 个品种的 runs 画像

如果把 55 个品种摊开在一张地图上，每个品种都是一个点，横轴是方向准确率，纵轴是回归 R²，那么这张图会呈现出明显的分层。

右上角聚集着一批"优等生"：沪金、沪铝、焦煤、铁矿石、菜油、棕榈油……它们的方向准确率在 80% 以上，回归 R² 也多在 0.1 以上。

左下角散落着一批"掉队者"：花生、生猪、欧线集运、多晶硅、红枣……方向准确率徘徊在 50%-55%，基本等同于抛硬币。

中间地带是大多数品种：准确率 65%-75%，R² 0.05-0.15，信号存在但不够强。

每个品种平均识别出约 26 个 runs，但 runs 的数量和质量的分布并不均匀。有的品种（如尿素、乙二醇、纸浆）识别出了 30 个以上的 runs，说明这些品种的主力走势较为"碎"——趋势切换频繁，每次积累的幅度不大。有的品种（如沪金、燃油、焦煤）只有 22 个 runs，说明它们的主力走势更"整"——一旦形成趋势，会持续较长时间。

### 3.2 头部品种：沪金、沪铝、焦煤们的共同基因

Plan 3 方向准确率最高的五个品种是：

| 品种 | 方向准确率 | runs 数 | 板块 |
|------|-----------|---------|------|
| 沪金 | 95.5% | 22 | 有色金属 |
| 沪铝 | 91.7% | 24 | 有色金属 |
| 焦煤 | 90.9% | 22 | 黑色系 |
| 铁矿石 | 87.0% | 23 | 黑色系 |
| 菜油 | 87.0% | 23 | 油脂油料 |

这些头部品种有什么共同点？

**流动性好**是首要条件。沪金、沪铝、铁矿石都是各自板块里成交量最大的品种之一。流动性好意味着大单委托更容易被识别为主力资金，而不是被淹没在噪音中。

**定价逻辑清晰**是第二个条件。沪金的定价与全球金价高度联动，宏观逻辑明确；铁矿石的定价由全球钢铁需求和澳洲巴西供应主导，基本面透明。定价逻辑越清晰，主力资金的方向信号就越"干净"——因为它们不是在对赌散户，而是在对赌宏观趋势。

**机构投资者参与度高**是第三个条件。这些品种都是产业链上下游企业（矿山、钢厂、油脂加工厂）的套保重点。当产业资金（通常被识别为"主力"）持续入场时，它们往往不是投机性的短线操作，而是基于基本面判断的战略性布局。这种布局的持续性更强，因此 diff2 的连续同向特征更明显，cumulative_delta 的积累也更扎实。

沪金是一个极端案例。22 个 runs 中，11 个做多 run 的方向准确率是 100%——每一个主力持续做多的区间，价格都涨了。这在 55 个品种中是唯一的。沪金的特殊之处在于：它是全球市场定价的品种，国内金价紧跟国际金价，而国际金价的波动主要受美元走势、地缘政治、通胀预期等宏观因素驱动。当国内主力持续做多沪金时，往往意味着国际宏观环境也在支持金价上涨。主力信号和宏观趋势形成了共振，准确率自然接近完美。

### 3.3 尾部品种：花生、生猪为什么失灵

另一端的故事同样值得深究。

**花生**：方向准确率 51.9%，binom_p = 1.0。基本随机。

花生的问题在于流动性太差。55 个品种中，花生的成交量长期处于尾部。流动性差意味着大单委托的统计不稳定——一笔稍大的订单就可能被误判为"主力"，而实际上可能只是某个产业客户的正常套保。信号被噪音淹没，方向准确率自然上不去。

**生猪**：方向准确率 50.0%，但结构极其畸形——做多准确率仅 15.4%，做空准确率 84.6%。

这是一个非常反常的模式。它意味着：当主力持续做多生猪时，价格几乎总是下跌；但当主力持续做空时，价格大多数时候确实下跌。换句话说，主力的"做空判断"是对的，但"做多判断"是错的。

为什么？生猪是农产品中受政策影响最大的品种之一。收储、放储、进口配额、疫病防控……政策可以在短时间内完全逆转市场供需。当主力基于基本面判断"做多"时，政策可能突然转向，导致价格反向运动。而"做空"往往是在政策利空已经释放、市场恐慌情绪蔓延时发生的，此时价格向下的阻力较小。

生猪的教训是：**当政策因素主导定价时，任何基于订单流的技术信号都可能失效。** 主力资金也可能在政策面前犯错。

**欧线集运**：55.2%，p = 0.711。与 Plan 1 一样，欧线集运是全市场的异类。

欧线集运的定价完全由航运供需周期驱动——航线运力、集装箱供需、港口拥堵指数。这些基本面因素与"大单委托"几乎无关。航运公司的套保行为可能被识别为"主力"，但实际上它们只是在锁定运价风险，而不是在"预测"价格方向。Plan 1 就发现欧线集运是散户反向规律唯一失效的品种，Plan 3 进一步确认了它作为"主力信号盲区"的地位。

### 3.4 板块格局：有色金属为什么一直赢

如果把 55 个品种按板块分组，会得到一张清晰的层级图：

| 板块 | 平均方向准确率 | 平均回归 R² | 品种数 |
|------|-------------|------------|--------|
| 有色金属 | **82.5%** | 0.2079 | 9 |
| 黑色系 | **77.2%** | 0.2793 | 5 |
| 化工能化 | **73.5%** | 0.1191 | 18 |
| 油脂油料 | **73.4%** | 0.2792 | 8 |
| 其他 | **66.0%** | 0.2967 | 8 |
| 农产品 | **65.2%** | 0.1571 | 7 |

有色金属以 82.5% 的平均准确率傲视全市场，而且 9 个品种全部通过门槛。这不是偶然。

有色金属的定价有一个独特的特征：**国际化程度高**。沪铜、沪铝、沪锌的价格与国际 LME 市场高度联动，沪金、沪银直接挂钩 COMEX。这意味着国内主力资金的动向不是"闭门造车"，而是与全球资本流动同步。当国内主力持续做多沪铜时，往往国际铜价也在涨——国内信号和国际趋势形成了双重确认。

黑色系的强势则来自另一个维度：**产业链集中度高**。铁矿石的供应被澳洲和巴西四大矿山垄断，下游需求被中国钢厂主导。这种"上游集中、下游集中"的产业链结构，使得价格更容易被大资金推动。当钢厂集体做多铁矿石（套保或投机）时，它们的订单体量足够大，信号足够强，不会被噪音淹没。

农产品排名垫底（65.2%），原因是**定价受季节性因素和政策因素主导**。玉米的播种面积、白糖的榨季、苹果的霜冻、生猪的疫病……这些基本面因素可以在短时间内完全覆盖主力资金的信号。主力可能基于当前供需判断"做多"，但一场突如其来的政策调控就能让价格反向运动。

化工能化板块是一个有趣的中游地带。18 个品种、平均准确率 73.5%，不算顶尖但也不差。这个板块的特点是**品种间分化极大**：纯碱（80.0%）和苯乙烯（83.3%）在头部，而 LPG（70.4%）和沥青（70.4%）在尾部。分化大的原因可能是化工品的定价逻辑差异太大——有的挂钩原油（如燃油、低硫燃油），有的挂钩煤化工（如甲醇、尿素），有的有独立的产业链逻辑（如 PTA、PVC）。统一的"主力信号"框架在不同化工品上的适用性天然就有差异。

### 3.5 多空不对称：做多的力量更强

Plan 3 的一个意外发现是多空不对称。

从方向准确率看，做多 runs（73.36%）和做空 runs（71.97%）差别不大，只差了 1.4 个百分点。但如果看回归斜率，差异就很明显了：

| 方向 | 回归斜率 | R² | p 值 |
|------|---------|-----|------|
| 做多 | 0.0155 | 0.0679 | 1.35×10⁻¹² |
| 做空 | 0.0091 | 0.0412 | 2.78×10⁻⁸ |

做多 runs 的斜率是做空的 1.7 倍。这意味着：同样幅度的 |cumulative_delta|，对价格上涨的推动力是对价格下跌的推动力的 1.7 倍。

为什么？

一个可能的解释是**资金成本的不对称**。做多期货需要保证金，持仓期间还要支付资金成本；做空同样需要保证金，但理论上可以通过持有现货来对冲。在商品期货市场，产业链上下游企业（如矿山、钢厂、油厂）的天然头寸往往是"多头"（持有现货），它们的套保需求以"卖出套保"为主。当这些产业资金持续做空时，往往意味着它们在锁定现货利润，而不是在"押注"价格下跌。这种"被动做空"的信号强度，自然弱于"主动做多"的投机资金。

另一个可能的解释是**市场情绪的不对称**。牛市中的贪婪和熊市中的恐惧，对价格的推动力度不同。当主力持续做多时，市场情绪往往是乐观的，散户跟风买入，形成正反馈；当主力持续做空时，市场情绪可能是恐慌的，但也可能是"观望"的——散户可能选择离场而不是跟风做空，导致价格向下的动能不足。

这个发现对策略设计有直接影响：如果基于主力持续单向积累构建交易系统，应该对做多信号给予更高的权重，或者对做空信号设置更严格的过滤条件。

### 3.6 从 Plan 1 到 Plan 3：哪些品种"掉队了"

一个值得玩味的对比是：Plan 1 有 45 个品种通过门槛（81.8%），Plan 3 只有 31 个（56.4%）。

为什么会少这么多？

因为 Plan 3 的检验更严格。Plan 1 只要求"方向一致"——在一个 3 天的滑窗内，主力方向和价格方向相同就算成功。Plan 3 要求"在持续单向运动的区间内，方向一致"——这不仅要求方向对，还要求主力确实在"持续"地朝一个方向积累。

有些品种在 Plan 1 中表现不错，但在 Plan 3 中掉了下来。比如沪银：Plan 1 同向率 70.1%（排名第 8），Plan 3 准确率 73.1%（排名第 28），刚好卡在通过线边缘。再比如 PTA：Plan 1 同向率 67.2%，Plan 3 准确率 77.8%，排名反而上升了。

"掉下来"的品种有一个共同特征：它们的主力走势"碎"——趋势切换频繁，很少有持续时间较长的单向运动。Plan 1 的固定滑窗可以把这些碎片拼接成"看起来正确"的方向判断，但 Plan 3 的 run 检测把这些碎片打回了原形。

"升上去"的品种则相反：它们的主力走势"整"——一旦形成趋势，会持续较长时间。Plan 3 的 run 检测恰好捕捉到了这些"整"的品种的优势。

这个对比揭示了一个重要的策略启示：**不是"所有品种都能用主力信号"，而是"只有那些主力走势'整'的品种才值得用"。** 对于主力走势"碎"的品种，与其跟踪主力信号，不如用其他方法（如趋势跟踪、均值回归）。

## 四、横纵交汇洞察

### 4.1 历史如何塑造了当下的品种格局

把纵向的方法演进和横向的品种差异放在一起看，会发现一个清晰的因果链。

Plan 1 的方法是"固定滑窗"——它假设所有品种、所有时间段都可以用同一个时间尺度（3 天）来度量。这个假设在统计学上是方便的，但在经济学上是粗暴的。不同品种的价格运动频率不同：沪金可能一周才完成一次趋势切换，而生猪可能三天就来回震荡一次。用同一个 3 天窗口去量它们，相当于用同一把尺子去量蚂蚁和大象。

Plan 3 的方法是"动态 run 检测"——它让数据自己决定"一个趋势有多长"。沪金的趋势可能持续 10 天，生猪的可能只持续 3 天。这个方法论的演进，本质上是从"一刀切"到"因品种制宜"。

而横向的品种格局，恰好验证了这个方法论选择的正确性。有色金属和黑色系的主力走势最"整"，所以 Plan 3 的检测方法对它们最有利；农产品的主力走势最"碎"，所以 Plan 3 的严格筛选把它们大量过滤掉了。

如果反过来，Plan 3 仍然用固定滑窗，会怎么样？所有品种都会被"一视同仁"地切分，有色金属的"整"优势被抹平，农产品的"碎"劣势被掩盖。最终的结果会是一个模糊的"所有品种平均准确率 65%"，但没有任何一个品种的信号质量被真正看清。

方法论的演进（纵向）和品种格局的形成（横向），在这里是同一个硬币的两面。

### 4.2 信号纯度与品种特性的深层关联

再往下追问一层：为什么有些品种的主力走势"整"，有些"碎"？

答案藏在品种的基本面特性里。

**国际化程度**决定了价格运动的"惯性"。国际化程度高的品种（如沪金、沪铜），其价格受全球市场驱动，宏观趋势一旦形成，往往持续数周甚至数月。这种"惯性"反映在主力指数上，就是持续的单向运动——因为全球资本在持续流入或流出。

**产业链集中度**决定了主力资金的"一致性"。产业链上游或下游高度集中的品种（如铁矿石、焦煤），少数几个大玩家的行为就能主导市场方向。当它们达成一致预期时，主力指数会呈现清晰的单向趋势。当它们分歧时，主力指数会震荡——但这种分歧本身也是信号，意味着趋势即将反转。

**政策敏感度**决定了信号的"噪声水平"。政策敏感度高的品种（如生猪、尿素、苹果），价格经常被不可预测的政策事件打断。主力可能基于正常基本面判断"做多"，但一场收储公告就能让价格暴跌。这种"外生冲击"使得主力信号的纯度大幅下降。

**流动性**决定了信号的"可检测性"。流动性差的品种（如花生、原木），单笔大订单就能扭曲主力指数的统计，导致信号被噪音淹没。

这四个维度——国际化、集中度、政策敏感度、流动性——构成了一个"信号纯度评估框架"。未来的品种筛选，可以从这四个维度入手，而不是单纯依赖历史回测的准确率。

### 4.3 三个剧本

基于纵向趋势和横向格局，可以推演三种未来剧本。

**最可能的剧本：分层使用，有色金属和黑色系作为核心池**

主力持续单向积累信号在有色金属（82.5%）和黑色系（77.2%）上的表现足够稳定，可以作为核心策略池。化工能化和油脂油料作为卫星池，需要加入额外的过滤条件（如成交量确认、波动率过滤）。农产品和"其他"板块的尾部品种建议排除。

策略设计上，做多信号的权重大于做空（斜率 0.0155 vs 0.0091），高质量 run（|cumulative_delta| 在顶部 1/3）对应更大的仓位。止损逻辑可以基于"run 被反向突破"——即 diff2 的符号首次反转时平仓。

**最危险的剧本：R² 偏低导致实际交易效果不佳**

Plan 3 的回归 R² 只有 5.56%。这意味着即使信号方向正确，价格变动的幅度也很难被精确预测。在实际交易中，可能出现"方向对了但幅度不够"的情况——信号说"涨 5%"，实际只涨了 1%，扣除交易成本和滑点后无利可图。

更危险的是，当前数据区间只有 180 个交易日（约 8 个月），样本外稳定性未经验证。如果未来市场结构发生变化（如某个品种引入新的套保工具、某个板块受到新的政策调控），信号的有效性可能迅速衰减。

**最乐观的剧本：与散户反向信号复合，构建双因子模型**

Plan 1 已经验证了"散户反向"规律（散户方向与价格方向反向率 64.4%）。Plan 3 验证了"主力持续积累"规律（方向准确率 72.66%）。两个信号高度相关（主力与散户反向率 76.9%），但捕捉的是不同的信息维度。

如果把两者复合，构建一个"主力质量 + 散户对立度"的双因子模型，可能会产生 1+1 > 2 的效果。例如：只在"主力高质量积累 + 散户强烈反向"的区间开仓，同时满足两个条件时，信号的置信度会大幅提升。

复合模型的另一个方向是引入成交量和波动率作为辅助过滤条件。cumulative_delta 解释了 5.6% 的方差，如果再加上成交量确认（主力积累期间成交量显著放大），解释力可能提升到 10% 以上——这在量化因子中已经是相当不错的水平。
