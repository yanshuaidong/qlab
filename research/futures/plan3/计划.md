# Plan 3：主力持续单向积累与期货价格变动幅度的关系验证

## 研究前提

- [Plan 1 报告](../plan1/docs/report.md) — 已证明主力方向与价格方向一致性 ~66%，散户反向对称成立
- [数据库说明](../../../storage/futures/futures_main_retail/README.md) — `fut_strength.main_force` 与 `fut_daily_close.close_price`

## 核心假设

**大趋势 = 主力资金的持续单向积累**

即：主力指数持续单调运动的时间越长、积累幅度越大，期货价格变动就越大。

## 指标定义

| 符号 | 含义 |
|------|------|
| `t` | 当前交易日 |
| `t-2` | 前天（用 2 日差过滤噪声） |
| `main_force[t]` | 当前交易日的主力指数 |
| `z_score[t]` | `main_force[t]` 在同品种历史中的标准化值（品种内 z-score） |
| `diff2[t]` | `z_score[t] - z_score[t-2]` |
| `sign[t]` | `+1`（diff2 > 0）、`-1`（diff2 < 0）、`0`（diff2 = 0） |

> 主力指数的正负代表多空方向，绝对值代表力量大小。
> 主力指数必须与同品种历史比较，不能跨品种比绝对值。

## 研究方法

### Step 1：数据预处理

对每个品种，将 `main_force` 做 z-score 标准化（均值 0，标准差 1），使品种内可比较、品种间可汇总。

### Step 2：连续单调区间识别

每天计算 `diff2[t] = z_score[t] - z_score[t-2]`，标记符号，将连续相同符号的交易日合并为一个 **run**。

**过滤规则**：`duration ≤ 2` 日的 run 视为噪声，过滤掉。

**run 的核心指标**：

| 指标 | 含义 |
|------|------|
| `duration` | run 中 diff2 的天数（即连续单调持续天数） |
| `direction` | `+1`（做多 run）、`-1`（做空 run） |
| `cumulative_delta` | `z_score[run_end] - z_score[run_start_anchor]`，即主力指数在 run 期间的累积变化量 |
| `price_change%` | `(close[run_end] - close[run_start_anchor]) / close[run_start_anchor]`，即同期价格变化率 |

### Step 3：检验方法

三层验证，由浅到深：

#### 3.1 方向准确率
- 做多 run 中 `price_change% > 0` 的比例
- 做空 run 中 `price_change% < 0` 的比例
- 判断是否显著高于 50%

#### 3.2 质量分组检验（核心假设的直接验证）
将 runs 按 `|cumulative_delta|` 绝对值分三组（低/中/高），验证三组 `|price_change%|` 均值是否递增：
- 低质量组（底部 1/3）：主力小幅积累 → 价格变化小
- 中质量组（中间 1/3）：主力中等积累 → 价格变化中等
- 高质量组（顶部 1/3）：主力大幅积累 → 价格变化大

#### 3.3 回归验证
`|price_change%| ~ |cumulative_delta|` 线性回归，检验：
- 斜率是否显著 > 0
- R² 大小（解释力）

### Step 4：分析维度

| 维度 | 内容 | 目的 |
|------|------|------|
| 品种级 | 每个品种单独做方向准确率 + 回归 | 观察规律在不同品种上的稳定程度 |
| 全局汇总 | 所有品种的 runs 合并统计 | 验证全局趋势是否普遍成立 |
| 多空拆分 | 做多 run 和做空 run 分开统计 | 观察涨跌趋势的对称性差异 |
| 板块汇总 | 按有色金属/化工/油脂等板块分组 | 观察 Plan 1 的板块强弱是否延续 |
