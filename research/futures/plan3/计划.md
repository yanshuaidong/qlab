# 计划 3：信号后的价格路径同步率与趋势延续质量验证

## 0. 这次要回答什么

计划 1 已经验证：在全市场 55 个品种中，`main_force` 与期货价格在 S=3 滑窗下存在稳定同期共振；`retail` 与价格大体反向。

计划 2 已经把这个结构落成可交易口径：严格 **5+3 重合 = 7 个交易日** 的 A 通道信号，之后用 3 日 `main_force` 拐头离场，并在 12 个跨板块品种池上验证过组合效果。

计划 3 不改策略主逻辑，只研究一个更细的问题：

> 当 5+3（7 日）信号出现后，价格本身在最近 3 日、最近 7 日、过去 14 日的路径，是否会影响这个信号的质量？

具体说：

1. 信号日 t 的近 3 日价格趋势，用 `close(t) - close(t-2)` 判断。  
   做多信号出现后，价格近 3 日已经上涨还是仍在下跌，对未来是否有影响？做空同理。
2. 价格在信号形成窗口 `t-6..t` 里，是否也像主力那样“先反向走、再拐向开仓方向”？这种同步程度越高，信号是不是越好？
3. 价格在更长窗口 `t-13..t` 里，是否也完成了类似的同步结构？14 日同步率是否能过滤掉更大的逆势环境？
4. 信号出现后，价格会不会继续延续近 3 日趋势？未来 3、5、7、10 日的延续概率、收益、回撤是否有差异？

一句话：**计划 3 回答“同样是主力 5+3 信号，哪一种价格路径更值得信任”。**

## 2. 方向统一：把多空都转成“顺信号方向”

为了让多头和空头可以放在一起统计，所有价格变化都转成信号方向收益：

| 变量 | 做多信号 | 做空信号 |
|------|----------|----------|
| `side` | +1 | -1 |
| 顺信号价格变化 | `close(b) - close(a)` | `close(a) - close(b)` |
| 顺信号收益 | `close(b) / close(a) - 1` | `1 - close(b) / close(a)` |

统一公式：

```text
signed_return(a,b) = side * (close(b) / close(a) - 1)
signed_delta(a,b)  = side * (close(b) - close(a))
```

含义：

- `signed_return > 0`：价格朝信号方向走；
- `signed_return < 0`：价格逆信号方向走。

这样做多和做空都能用同一套指标判断。

## 3. 研究指标一：近 3 日价格趋势

### 3.1 定义

信号日 t 的近 3 日价格趋势，用 `t-2` 到 `t` 的收盘价变化：

```text
price_trend_3 = sign(side * (close(t) - close(t-2)))
price_ret_3   = side * (close(t) / close(t-2) - 1)
```

分组：

| 分组 | 条件 | 含义 |
|------|------|------|
| `P3_follow` | `price_trend_3 > 0` | 信号出现时，价格近 3 日已经顺信号方向走 |
| `P3_against` | `price_trend_3 < 0` | 信号出现时，价格近 3 日仍逆信号方向走 |
| `P3_flat` | `price_trend_3 = 0` | 近 3 日价格基本不动 |

### 3.2 要检验的问题

做多信号中：

- 若 `close(t) > close(t-2)`，说明价格已经跟着主力拐头向上；
- 若 `close(t) < close(t-2)`，说明主力已经拐头，但价格还没跟上。

计划 3 要判断：

- `P3_follow` 是否代表更高胜率、更大未来收益；
- `P3_against` 是否是低质量信号，还是反而代表“价格尚未启动、赔率更好”；
- 近 3 日价格涨幅过大时，是否会带来短期追高风险。

### 3.3 输出指标

按 `P3_follow / P3_against / P3_flat` 分组输出：

| 指标 | 观察窗口 |
|------|----------|
| 未来顺信号收益均值/中位数 | 3、5、7、10 日 |
| 胜率：`future_signed_return > 0` | 3、5、7、10 日 |
| 延续率：未来收益方向是否延续 `price_trend_3` | 3、5、7、10 日 |
| 最大不利波动 MAE | 3、5、7、10 日 |
| 最大有利波动 MFE | 3、5、7、10 日 |
| 样本数 | 每组、每品种、每板块 |

## 4. 研究指标二：7 日价格同步率

### 4.1 为什么不能只看 t 和 t-6

用户提出的“同步”不是简单的首尾涨跌，而是路径形状：

- 做多信号：主力先持续弱，达到极端低点，再连续回升；理想价格路径是先跌，然后拐头向上。
- 做空信号：主力先持续强，达到极端高点，再连续回落；理想价格路径是先涨，然后拐头向下。

所以同步率要同时看两件事：

1. 背景段价格是否先逆信号方向走；
2. 触发段价格是否再顺信号方向走。

### 4.2 7 日窗口切分

信号日 t：

- 背景价格段：`t-6..t-2`
- 触发价格段：`t-2..t`
- 7 日完整路径：`t-6..t`

### 4.3 7 日同步的两个分项

**背景同步：**

```text
bg_sync_7 = 1 if side * (close(t-2) - close(t-6)) < 0 else 0
```

含义：

- 做多：`close(t-2) < close(t-6)`，价格先跌；
- 做空：`close(t-2) > close(t-6)`，价格先涨。

**触发同步：**

```text
turn_sync_7 = 1 if side * (close(t) - close(t-2)) > 0 else 0
```

含义：

- 做多：`close(t) > close(t-2)`，价格再向上；
- 做空：`close(t) < close(t-2)`，价格再向下。

### 4.4 7 日同步率主指标

主指标使用 0、0.5、1 三档，避免过度拟合：

```text
price_sync_7 = 0.5 * bg_sync_7 + 0.5 * turn_sync_7
```

| 分数 | 含义 |
|------|------|
| 1.0 | 完整同步：价格先逆信号方向走，再顺信号方向拐头 |
| 0.5 | 半同步：只满足背景段或触发段之一 |
| 0.0 | 不同步：两段都不符合 |

### 4.5 7 日同步的增强指标

除了三档主指标，再保留两个连续变量，方便做回归：

```text
bg_ret_7   = -side * (close(t-2) / close(t-6) - 1)
turn_ret_7 =  side * (close(t)   / close(t-2) - 1)
```

含义：

- `bg_ret_7 > 0`：背景段价格按理想方向先反向压下去；
- `turn_ret_7 > 0`：触发段价格按信号方向拐回来；
- 两者都越大，路径越接近“先压、再拐”的形状。

可定义一个连续同步强度：

```text
price_sync_strength_7 = zscore(bg_ret_7) + zscore(turn_ret_7)
```

`zscore` 在同品种内部计算，避免不同品种波动率不同导致不可比。

## 5. 研究指标三：14 日价格同步率

### 5.1 14 日窗口的作用

7 日同步看的是信号形成窗口本身，14 日同步看的是更大的价格环境：

- 如果 7 日同步强，但 14 日仍处在大级别反向趋势中，信号可能只是短反弹；
- 如果 14 日也完成“先反向、再拐头”，说明价格结构更完整，可能更利于延续。

### 5.2 14 日窗口切分

信号日 t：

- 长背景段：`t-13..t-2`
- 触发段：`t-2..t`
- 完整窗口：`t-13..t`

### 5.3 14 日同步主指标

```text
bg_sync_14 = 1 if side * (close(t-2) - close(t-13)) < 0 else 0
turn_sync_14 = 1 if side * (close(t) - close(t-2)) > 0 else 0

price_sync_14 = 0.5 * bg_sync_14 + 0.5 * turn_sync_14
```

注意：`turn_sync_14` 与 `turn_sync_7` 本质一致，都是 `t-2..t` 的触发段。区别在于背景段从 `t-6..t-2` 扩展为 `t-13..t-2`。

### 5.4 14 日连续同步强度

```text
bg_ret_14   = -side * (close(t-2) / close(t-13) - 1)
turn_ret_14 =  side * (close(t)   / close(t-2)  - 1)

price_sync_strength_14 = zscore(bg_ret_14) + zscore(turn_ret_14)
```

## 6. 未来结果变量

对每个信号日 t，观察未来 3、5、7、10 个交易日。

### 6.1 固定持有收益

```text
future_ret_h = side * (close(t+h) / close(t) - 1)
```

其中 `h ∈ {3,5,7,10}`。

### 6.2 趋势延续率

近 3 日价格趋势为：

```text
price_trend_3 = sign(side * (close(t) - close(t-2)))
```

未来 h 日趋势为：

```text
future_trend_h = sign(side * (close(t+h) - close(t)))
```

延续定义：

```text
trend_continue_h = 1 if price_trend_3 == future_trend_h and price_trend_3 != 0 else 0
```

主要回答：**如果信号日近 3 日价格已经顺信号方向走，未来 3/5/7/10 日是否继续顺着走？**

### 6.3 MAE / MFE

对未来 h 日内每一天 k：

```text
path_ret_k = side * (close(t+k) / close(t) - 1)
```

则：

```text
MFE_h = max(path_ret_1 ... path_ret_h)
MAE_h = min(path_ret_1 ... path_ret_h)
```

用途：

- `future_ret_h` 看最终结果；
- `MFE_h` 看有没有给过盈利机会；
- `MAE_h` 看进场后最大逆行风险。

## 7. 分析方法

### 7.1 单变量分组

先分别按以下变量分组：

- `price_trend_3`：`P3_follow / P3_against / P3_flat`
- `price_sync_7`：`0 / 0.5 / 1`
- `price_sync_14`：`0 / 0.5 / 1`

每组输出未来 3、5、7、10 日：

- 样本数；
- 平均收益；
- 中位数收益；
- 胜率；
- MAE 均值；
- MFE 均值；
- 收益分布分位数：25%、75%。

每个分组都要输出三套口径：

| 口径 | 用途 |
|------|------|
| 全市场综合 | 回答同步率总体是否有效 |
| 分品种 | 回答每个品种是否适合同步率过滤 |
| 分板块 | 回答规律是否有明显板块差异 |

分品种表不能只给最终排名，还要保留每个品种在 `P3_follow / P3_against / sync7 / sync14` 下的样本数、胜率、平均收益和 MAE。样本数不足的品种标记为 `样本不足`，不强行下结论。

### 7.2 联合分组

重点看以下组合：

| 组合 | 含义 |
|------|------|
| `P3_follow & sync7=1` | 价格近 3 日已经顺信号，并且 7 日路径完整同步 |
| `P3_follow & sync7<1` | 近 3 日顺信号，但完整路径不够标准 |
| `P3_against & bg_sync_7=1` | 背景段符合“先压”，但触发段价格还没跟上 |
| `P3_against & bg_sync_7=0` | 背景段和触发段都没配合，疑似低质量信号 |
| `sync7=1 & sync14=1` | 短窗与长窗都同步 |
| `sync7=1 & sync14=0` | 短窗同步，但大背景不配合 |

联合分组要特别注意样本数。若某组样本太少，不做结论，只做提示。

### 7.3 回归检验

用简单、可解释的横截面回归，不搞复杂模型：

```text
future_ret_h
  ~ price_ret_3
  + price_sync_7
  + price_sync_14
  + main_score
  + C(variety)
```

其中：

- `price_ret_3`：近 3 日价格顺信号收益；
- `price_sync_7`：7 日同步三档分数；
- `price_sync_14`：14 日同步三档分数；
- `main_score`：计划 2 中已有的主力 3 日动量分位；
- `C(variety)`：品种固定效应，控制品种差异。

目标不是预测，而是看：

- `price_ret_3` 是否显著；
- `price_sync_7` 是否显著；
- `price_sync_14` 是否在控制 7 日同步后仍有增量；
- 这些价格指标是否只是 `main_score` 的替代品，还是能提供独立信息。

### 7.4 全品种横截面排序

计划 3 需要单独输出一个“品种适配度”表，把每个品种对价格路径同步率的敏感度列出来。

建议字段：

| 字段 | 含义 |
|------|------|
| `variety_name` | 品种 |
| `sector` | 板块 |
| `signal_count` | 信号总数 |
| `p3_follow_count` / `p3_against_count` | 近 3 日顺/逆信号样本数 |
| `p3_follow_winrate_h` / `p3_against_winrate_h` | 未来 h 日胜率对比 |
| `p3_follow_avg_ret_h` / `p3_against_avg_ret_h` | 未来 h 日平均收益对比 |
| `sync7_full_count` | 7 日完整同步样本数 |
| `sync7_full_avg_ret_h` | 7 日完整同步未来收益 |
| `sync7_edge_h` | `sync7=1` 相对 `sync7<1` 的收益差 |
| `sync14_edge_h` | `sync14=1` 相对 `sync14<1` 的收益差 |
| `suggested_use` | `硬过滤 / 排序加分 / 反向观察 / 样本不足 / 不使用` |

其中 `h` 重点看 3、5、7、10 日全部窗口，但报告正文优先解释 5 日和 7 日；3 日太短，10 日可能已经混入新的主力变化。

### 7.5 策略消融

消融分两层做。

第一层是**信号级消融**，对全市场所有信号统一统计，不引入组合槽位：

| 版本 | 规则 |
|------|------|
| baseline_all | 全品种所有 5+3 信号 |
| filter_p3_follow | 只做近 3 日价格已顺信号方向的信号 |
| filter_sync7_full | 只做 `price_sync_7 = 1` 的信号 |
| filter_sync14_full | 只做 `price_sync_14 = 1` 的信号 |
| filter_p3_follow_bg7 | 只做 `P3_follow` 且 `bg_sync_7 = 1` 的信号，等价于完整 7 日同步 |
| filter_p3_follow_bg14 | 只做 `P3_follow` 且 `bg_sync_14 = 1` 的信号，检验长背景约束 |
| p3_against_only | 只做近 3 日价格仍逆信号方向的信号，验证“价格滞后是否更有赔率” |

对每个版本输出：

- 信号数；
- 胜率；
- 平均收益；
- 中位数收益；
- MAE / MFE；
- 被过滤掉的信号数；
- 分品种改善/恶化数量。

第二层是**计划 2 子样本组合消融**，只作为附录：在计划 2 的 12 品种组合策略上测试同步率过滤是否改善组合表现。它不作为计划 3 的主结论，只用于连接前两个计划。

## 8. 判定标准

### 8.1 认为“近 3 日价格趋势有用”的标准

满足以下至少两条：

- `P3_follow` 在未来 3/5/7/10 日中至少两个窗口胜率高于 `P3_against`；
- `P3_follow` 的平均收益或中位数收益明显高于 `P3_against`；
- `P3_follow` 的 MAE 更小，说明进场后更少先挨打；
- 分品种看，超过半数有效样本品种呈现同方向改善，而不是只由少数品种贡献；
- 回归里 `price_ret_3` 系数方向稳定，且不被 `main_score` 完全解释。

如果 `P3_against` 收益更高，则说明价格滞后反而可能提供更好赔率，这会成为下一版策略的重要发现。

### 8.2 认为“7 日同步率有用”的标准

满足以下至少两条：

- `price_sync_7 = 1` 的未来收益和胜率高于 `0.5` 与 `0`；
- `price_sync_7 = 1` 的 MAE 更小；
- `filter_sync7_full` 信号级消融虽然样本数下降，但收益、胜率或 MAE 质量改善；
- 分品种看，`sync7_edge` 为正的品种数量明显多于为负的品种；
- 回归里 `price_sync_7` 对未来收益有稳定正向贡献。

### 8.3 认为“14 日同步率有用”的标准

14 日指标比 7 日更容易牺牲样本数，所以要求更谨慎：

- 若 `sync7=1 & sync14=1` 明显优于 `sync7=1 & sync14=0`，说明长背景有用；
- 若 14 日过滤导致交易次数大幅下降且收益没有提升，则不作为硬过滤；
- 若 14 日只降低回撤，可考虑作为排序加分项，而不是开仓门槛。
- 若 14 日效果只出现在少数板块或少数品种，报告中按“品种/板块适配”处理，不写成全市场统一规则。

## 10. 预期结论类型

计划 3 不预设哪个答案一定正确，只把可能结论分成五种：

### 结论 A：价格同步越高，信号越好

如果成立，下一版策略可以：

- 全市场统一要求 `price_sync_7 = 1`；
- 或者同日多信号排序时优先 `price_sync_7` 高的品种；
- 对 `sync7=0` 的信号降权或跳过。

### 结论 B：近 3 日已经顺信号方向更好

如果成立，说明价格已经确认主力拐头，策略应更偏“确认后跟随”。

下一版策略可以：

- 全市场统一只做 `P3_follow`；
- 或把 `price_ret_3` 作为排序加分；
- 对 `P3_against` 延后一日观察。

### 结论 C：近 3 日仍逆信号方向反而更好

如果成立，说明主力先动、价格滞后，策略的优势来自抢在价格启动前。

下一版策略就不应该过滤 `P3_against`，反而应该研究：

- 逆信号价格跌/涨到什么程度是好赔率；
- 多少逆行幅度意味着主力信号失败；
- 是否需要结合 MAE 设置保护线。

### 结论 D：14 日同步只降低交易数，没有增益

如果成立，14 日同步不进入策略，只保留为诊断字段。

### 结论 E：规律强烈分品种

如果成立，就不能写成全市场统一过滤规则，而要给每个品种打标签：

- 有些品种适合 `sync7=1` 硬过滤；
- 有些品种只适合把同步率作为排序加分；
- 有些品种价格滞后更有价值，不能过滤 `P3_against`；
- 有些品种样本不足或规律混乱，价格同步率只做复盘诊断。

这是计划 3 最重要的输出之一：**不仅告诉我们整体有没有用，还要告诉我们每个品种该不该用。**

## 11. 风险与注意事项

1. **样本数风险**：全品种综合样本会增加，但分品种后仍可能稀疏；每个品种必须报告样本数。
2. **不能偷看未来**：所有同步指标只能用 `t` 及以前的价格，未来 3/5/7/10 日只作为结果变量。
3. **不能用结果调阈值**：第一版只用 `0 / 0.5 / 1` 三档同步率，不优化具体阈值。
4. **多空必须统一方向**：所有收益都要转成 `side` 方向，否则做空样本会被统计反。
5. **不要急着改策略**：先证明价格路径指标有稳定增量，再决定是硬过滤、排序加分，还是只做交易复盘标签。

## 12. 和前两个计划的关系

- 计划 1 回答：`main_force` 与价格是否存在同期共振。
- 计划 2 回答：主力 5+3 信号能否组成可交易组合。
- 计划 3 回答：在全市场全品种已经出现主力 5+3 信号之后，价格路径是否能区分信号质量，以及这种区分是否因品种而异。

所以计划 3 的边界很清楚：**它不是发明新信号，而是给已验证信号做质量分层。**
