# 计划 3：12 品种单品种逐笔交易明细分析

**数据来源**：策略 2 品种池（12 个品种）各自独立运行策略 1（严格 7 日开仓 + 3 日拐头离场）
**数据区间**：2025-07-22 ～ 2026-04-20（180 个交易日）
**分析视角**：从"组合净值"下沉到"每一笔交易的完整生命周期"

---

## 一、为什么需要计划 3

策略 2 报告回答了"组合层约束是否有效"，但留下了一个关键的未回答问题：

**组合层的收益究竟来自哪里？**

- 是来自"某些品种天然就盈利多、其他品种天然就亏损多"？
- 还是来自"所有品种都有赚钱能力，组合层只是在合适的时间选到了合适的品种"？
- 焦煤单品种收益 38.76% 是个例还是普遍现象？

策略 2 报告给出了各品种对组合的累计贡献，但这反映的是"在组合约束下的表现"，不是"该品种脱离组合约束后的独立能力"。我们需要知道 **12 个品种各自独立跑策略 1 时的完整交易画像**，才能判断组合层的选品排序到底是在"锦上添花"还是"雪中送炭"。

## 二、核心分析框架

### 2.1 每个品种的输出指标（逐品种统计）

对 12 个品种分别独立回测（沿用策略 1：严格 7 日 + 3 日拐头），对每笔交易记录：

| 指标 | 口径 |
|------|------|
| 交易方向 | 多 / 空 |
| 开仓日期 | 信号触发日收盘 |
| 平仓日期 | 拐头触发日收盘 |
| 持有天数 | exit_date − entry_date（交易日） |
| 开仓价格 | 信号日收盘价 |
| 平仓价格 | 拐头日收盘价 |
| 单笔收益率 pnl | side × (exit − entry) / entry |
| 开仓时 main_score | 主力动量 30 日分位分（0~1） |
| 开仓时 main_force | 开仓日 main_force 原始值 |
| exit_reason | tp3_main_turn / final_close |

### 2.2 逐品种汇总统计

| 统计项 | 说明 |
|--------|------|
| 总交易次数 | 总笔数 |
| 胜率 | pnl > 0 的笔数占比 |
| 平均单笔收益率 | 全部 pnl 的均值 |
| 中位单笔收益率 | 全部 pnl 的中位数 |
| 单笔收益率标准差 | 波动性 |
| 最大单笔盈利 / 亏损 | max(pnl) / min(pnl) |
| 盈亏比 | 平均盈利 / 平均亏损的绝对值 |
| 平均持仓天数 | 全部 holding_days 的均值 |
| 多方向胜率 | 仅多头交易的胜率 |
| 空方向胜率 | 仅空头交易的胜率 |
| 多方向平均 pnl | 多头交易的平均收益率 |
| 空方向平均 pnl | 空头交易的平均收益率 |
| 累计收益率 | 该品种独立策略的净值终值 − 1 |
| 最大回撤 | 独立策略净值的最大回撤 |
| main_score 与 pnl 相关性 | 开仓 score 与最终 pnl 的相关系数 |

### 2.3 全品种横向对比

在逐品种统计的基础上，计算全品种（12 个）的整体指标：

| 指标 | 说明 |
|------|------|
| **全品种平均胜率** | 12 个品种胜率的算术平均 |
| 全品种加权胜率 | 按交易笔数加权的胜率 |
| 全品种平均单笔收益率 | 全部交易 pnl 的均值 |
| 胜率分布 | 12 个品种胜率的分布（最高/最低/中位/四分位） |
| 品种间相关性 | 各品种逐日收益率的相关系数矩阵 |

## 四、分析问题清单

拿到上述数据后，依次回答以下问题：

1. **品种分层**：哪些品种是"天生优质"（高胜率 + 高盈亏比）？哪些是"碰运气"（低胜率 + 盈亏比 ≈ 1）？哪些是"稳定亏损"？
2. **胜率集中度**：全品种平均胜率是多少？是集中在某几个品种拉高，还是普遍高于 50%？
3. **胜率与交易次数的关系**：交易次数少（<5 笔）的品种是否不稳定？需不需要排除低样本品种？
4. **多空不对称性**：是否有品种在多头和空头上表现差异极大？如果有，是否可以针对性地只做单向？
5. **score 的预测能力**：main_score（主力动量分位分）高的交易是否确实比 score 低的交易更赚钱？能否用 score 做二次过滤？
6. **持有天数与 PnL 的关系**：持有天数是否与收益率正相关？长持是否值得？
7. **品种间相关性**：不同品种的逐日收益率是否高度相关？如果是，组合层的分散效果会被削弱多少？
8. **与策略 2 组合层的对比**：组合层的实际品种选择是否真的选中了"独立盈利能力更强"的品种？

## 五、实施步骤

### Step 1：提取数据与计算信号

- 从数据库读取 12 个品种的 `main_force, retail, close_price` 数据
- 对每个品种运行 `compute_signals_strict7_tp3()`（沿用 plan1/plan2 的信号计算逻辑）
- 输出每个品种的逐日信号表

### Step 2：模拟逐笔交易

- 对每个品种独立运行策略 1 的逐笔交易模拟
- 记录每笔交易的完整信息（开仓日、平仓日、方向、价格、pnl、score）
- 输出每个品种的 `trades` DataFrame

### Step 3：逐品种汇总统计

- 对每个品种的 `trades` 计算 2.2 节的所有统计量
- 合并为逐品种汇总表

### Step 4：全品种整体统计与图表

- 合并所有交易为全品种池
- 计算全品种整体指标
- 生成 3.2 节的全部图表

### Step 5：撰写分析报告

- 按第四章的 8 个问题逐一回答
- 输出 `plan3/docs/report.md`

## 七、注意事项

1. **与策略 2 的关系**：本计划是策略 2 的补充诊断，不做组合层逻辑，只做单品种独立分析。不修改策略 1 的开平仓参数。
2. **数据库依赖**：脚本依赖 `local_fut_pulse.sqlite` 数据库中的 `fut_strength` 和 `fut_daily_close` 表，以及 `fut_variety` 表做品种映射。请确认数据库文件存在且结构一致。
3. **样本量限制**：180 天中每个品种的交易次数约 10~20 笔，单个品种的胜率统计置信区间较宽。全品种合并统计（12 品种 × 平均 15 笔 = ~180 笔）可以提供更可靠的总体判断。
4. **图表先行**：每个统计量建议先看图，再看数。偏离直觉的图形往往比偏离直觉的数字更有信息量。
