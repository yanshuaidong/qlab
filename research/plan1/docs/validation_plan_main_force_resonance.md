目标：主力、散户、期货价格的量化研究。

研究数据位于仓库根目录下的 `database/`（SQLite 与元数据）；说明见该目录中的 `README.md`。


我们的目标是研究；
main_force，retail，的组合衍生的各种量化因子，fut_daily_close；的影响；然后产生策略，产生交易模式；



**字段含义**：
- `main_force`（主力资金强弱）：基于大单（单笔手数较大的委托）的多空方向统计。算法按一定阈值将委托划分为大单，再计算当天大单整体的相对强弱与方向。**正值**表示主力/大户做多力量较强（大单开多更活跃），**负值**表示主力/大户做空力量较强（大单开空更活跃）。数值越大说明大单在该方向上的活跃度越高。

- `retail`（散户资金强弱）：计算逻辑与 `main_force` 相同，但统计对象为散单（单笔手数较小的委托）。正值表示散户做多较强，负值表示散户做空较强。


# 验证计划：main_force / retail / 价格 同期趋势关系

**范围**：单一品种（`variety_id = 1`），小范围验证阶段。  
**目标**：检验三条序列在同一时间窗口内，趋势方向是否存在结构性关联——不涉及收益、持有期、交易、选品种等下游问题。

---

## 核心思路

用**整窗首尾差分**量化趋势。对每个滑窗，取序列在窗口最后一天与第一天的差值（末 − 首）：

- 差值 > 0 → 方向 **+1（涨）**
- 差值 < 0 → 方向 **−1（跌）**
- 差值 = 0 → 方向 **0（持平）**

`main_force`、`retail`、`close_price` 各自独立算一个方向，不使用窗内逐步比较，避免震荡行情被批量归零后统计失真。

**举例（S = 2）**：窗口依次为 (Day1, Day2)、(Day2, Day3)……每个窗口只看首尾。若主力首尾差 > 0、收盘价首尾差也 > 0，则该窗口主力与价格**同向**；若主力为正而价格持平或下跌，则**不同向**。  
同向率 = 趋势一致的窗口数 / 全部有效窗口数。

---

## 核心假设

| 假设 | 表述 | 原假设 H0 |
|------|------|-----------|
| **H1 主力共振** | `main_force` 方向与 `close_price` 方向相同的窗口占比 > 50% | 方向独立，同向约 50% |
| **H2 散户反向** | `retail` 方向与 `close_price` 方向相反的窗口占比 > 50% | 方向独立，反向约 50% |

> 这是**同期**关系，不是预测关系——不看窗口之后发生了什么。

## 定义

### 窗内首尾差与方向

设窗口内某序列首值为 `X_first`、末值为 `X_last`（按交易日顺序）：

```
Δ = X_last − X_first
dir = sign(Δ)   →  +1 / −1 / 0
```

脚本在明细 CSV 中输出每个窗口的 `delta_*` 与 `dir_*`。

### 同向 / 严格反向

以 `main` 与 `close` 的配对为例（`retail` 与 `close` 同理）：

| 情形 | 条件 | 计入 |
|------|------|------|
| **同向** | `dir_main == dir_close`（含 0 == 0） | same |
| **严格反向** | 两者均非 0 且 `dir_main == −dir_close` | opp |
| **分母** | 全部有效窗口，不剔除方向为 0 的窗口 | — |

> 双方同步静止（均为 0）视为趋势一致，计入同向。

### 可调参数

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `S` | **2、3、4** | 滑窗跨度（连续交易日数） |
| `stride` | `1` | 滑窗起点步长（逐日滑动） |

## 实验步骤

1. **取数与对齐**：从 SQLite 读 `variety_id=1` 的 `fut_strength` 与 `fut_daily_close`，按 `trade_date` 升序内连接，得到 `date, main_force, retail, close`。
2. **滑窗**：对每个 S，从序列起点滑动到终点，生成所有不跨断点的定长窗，每窗一行。
3. **计算差分与方向**：对每个窗口计算三条序列的 `Δ` 与 `dir`。
4. **配对统计**（每个 S 分别做）：
   - `main ~ close`：主力与价格的同向率、反向率。
   - `retail ~ close`：散户与价格。
   - `main ~ retail`：看主力与散户是否多空分化。
5. **指标**：同向占比、反向占比、卡方独立性检验 p 值、相对 50% 的双侧精确二项检验 p 值；按价格涨窗 / 跌窗拆分，分别看同向比例。
6. **稳健性**：
   - S 取 2～4，看同向占比是否随窗长稳定。
   - 打乱 `dir_main` 做 bootstrap，对比零假设下的同向占比分布（按 S 分层）。
7. **可视化**（建议）：三条序列标准化叠图；同向占比随 S 变化的折线图。

---

## 判定准则

进入「全品种」阶段的参考条件：

- **H1**：在 S = 3（主报告窗）下同向占比 ≥ 55%，且二项检验 p < 0.05。
- **稳定性**：S ∈ {2, 3, 4} 的结论方向一致（均偏向同向 > 50%）。
- **分拆检验**：价格涨、跌两侧的主力同向比例都明显高于偶然，避免单边行情假象。
- **H2** 为辅助：记录 retail 反向占比及随 S 的稳定性，**不作为硬门槛**。

若不满足：回到定义层（S 的取值、是否过滤过小 `|Δ|` 等），再决定是否扩展。
