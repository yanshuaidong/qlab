# 小范围验证计划：main_force / retail / 期货价格 的同期趋势关系

适用范围：**单一品种（variety_id = 1）**，小范围验证阶段。
目标：**只研究三条序列在同一时间窗口内的变化趋势是否有方向性关系**，不涉及收益、持有期、交易、选品种等下游问题。

---

## 1. 核心假设

记窗口 `W = [t−K+1, t]`，在该窗口内：

- **H1（主力共振）**：`main_force` 的变化趋势方向 与 期货主连价格 `close_price` 的变化趋势方向 **相同** 的窗口占比 > 50%。
- **H2（散户反向）**：`retail` 的变化趋势方向 与 `close_price` 的变化趋势方向 **相反** 的窗口占比 > 50%。
- **原假设 H0**：两两之间方向独立，同向占比 ≈ 50%。

注意这是**同期**关系，不是预测关系——不看窗口之后发生了什么。

---

## 2. 数据范围

| 项 | 取值 |
|----|------|
| 品种 | `fut_variety.id = 1` |
| 字段 | `fut_strength.main_force`、`fut_strength.retail`、`fut_daily_close.close_price` |
| 对齐键 | `(variety_id, trade_date)` 内连接，仅保留两表均存在的交易日 |
| 时间范围 | 该品种在库的全部连续交易日 |
| 缺失处理 | 任一字段为 NULL 的交易日整行剔除；剔除后若产生日期跳空，视跳空处为"序列断点"，不跨断点拼接窗口 |

---

## 3. 关键定义

### 3.1 "变化趋势方向"的两种口径（都算，做对比）

给定窗口 W 和序列 X（X ∈ {main_force, retail, close}），先算 `ΔX_i = X_i − X_{i−1}`，共 K 个差分值。

- **口径 A（严格连续同号）**：当且仅当 K 个 Δ 全部 > 0 时方向 = +1；全部 < 0 时 = −1；其他情况方向 = 0（该窗口不纳入统计）。
- **口径 B（净变化符号）**：方向 = `sign(X_t − X_{t−K+1})`。每个窗口都有方向（除非净变化恰为 0）。

口径 A 更严格、样本更少；口径 B 更宽松、样本更多。两者都跑，看结论是否一致。

### 3.2 可调参数

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `K` | 3 | 窗口长度（交易日） |
| `dir_mode` | A 与 B 都算 | 方向口径 |
| `stride` | 1 | 窗口步长，默认逐日滑动 |

---

## 4. 实验步骤

1. **取数与对齐**：从 SQLite 读 variety_id=1 的 `fut_strength` 与 `fut_daily_close`，按 `trade_date` 升序内连接，形成 `df[date, main_force, retail, close]`。
2. **滑窗**：t 从 K 扫到末尾，生成窗口序列 `{W_t}`，跳过跨断点的窗口。
3. **算三个方向**：对每个 W_t，按口径 A 和 B 分别计算 `dir_main`、`dir_retail`、`dir_close` ∈ {+1, −1, 0}。
4. **配对统计**（分别在 A、B 两种口径下做）：
   - 只保留 `dir_main ≠ 0` 且 `dir_close ≠ 0` 的窗口，做 **main ↔ close** 2×2 列联表（±1 × ±1）。
   - 只保留 `dir_retail ≠ 0` 且 `dir_close ≠ 0` 的窗口，做 **retail ↔ close** 2×2 列联表。
   - 额外：**main ↔ retail** 2×2 列联表（研究主力与散户是否本身就反向）。
5. **指标**（每张列联表都算）：
   - 同向占比：`P(dir_X == dir_close)`。
   - 反向占比：`P(dir_X == −dir_close)`。
   - 卡方独立性检验 p 值；与 50% 的单侧二项检验 p 值。
   - 分方向拆开看：多头窗口里 close 也多头的比例、空头窗口里 close 也空头的比例，检查是否两个方向都成立（避免被单边行情拉高）。
6. **稳健性**：
   - `K ∈ {2, 3, 4, 5}` 网格，观察占比随 K 的单调性。
   - 按年份（或前/后半段）切分，观察时间稳定性。
   - 打乱 `dir_main` 顺序 1000 次做 bootstrap，给出零假设下同向占比的经验分布，对比实际值。
7. **可视化**（至少两张）：
   - 三条序列叠图（标准化后），窗口同向/反向用颜色标注。
   - 同向占比随 K 变化的折线图，A、B 两种口径各一条。

---

## 5. 判定准则（是否进入下一阶段）

进入"全品种"阶段需同时满足：

- H1 在 K=3 下，A 或 B 至少一种口径的同向占比 ≥ 55%，二项检验 p < 0.05。
- H1 在 K ∈ {2,3,4,5} 的多数单元（≥ 3/4）方向一致（都偏向同向 > 50%）。
- 多头窗口和空头窗口拆开看，两个方向都 > 50%（不是单边行情假象）。
- H2 作为辅助观察：记录 retail 反向占比及其稳定性，**不作为硬门槛**。

任一硬条件不满足：回到定义层重审（K、dir_mode、是否剔除 |ΔX| 过小的噪声窗口等），不进入全品种。

## 7. 待确认 / 已知歧义

1. **口径 A vs B**：两种都跑，结果若严重分歧，以 A（严格连续同号）为主，因为更贴近用户原话"连续同向变化"。
2. **品种 1 的业务含义**：未绑定具体商品 key；如需换成特定品种，改 variety_id 即可。
3. **"方向 = 0"的窗口占比**：若口径 A 下方向 = 0 的窗口过多（例如 > 70%），说明 K 或定义过严，需在回顾阶段调整。
