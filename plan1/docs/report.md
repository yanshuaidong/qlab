# 主力/散户与期货价格同期趋势共振验证报告

**品种范围**：全市场 55 个品种  
**数据区间**：2025-07-22 ～ 2026-04-20（每品种 180 个交易日）  
**方法**：整窗首尾差分；滑窗跨度 S ∈ {2, 3, 4}，逐日滑动（stride = 1）  
**报告日期**：2026-04-21

---

## 一、研究背景与核心假设

### 字段含义


| 字段            | 含义                                  |
| ------------- | ----------------------------------- |
| `main_force`  | 基于大单委托统计的主力资金强弱。正值→大单做多活跃；负值→大单做空活跃 |
| `retail`      | 基于散单委托统计的散户资金强弱。正负含义同上              |
| `close_price` | 当日期货收盘价                             |


### 核心假设


| 假设          | 表述                                             | 原假设 H0         |
| ----------- | ---------------------------------------------- | -------------- |
| **H1 主力共振** | `main_force` 与 `close_price` 同期方向一致的窗口占比 > 50% | 两者方向独立，同向约 50% |
| **H2 散户反向** | `retail` 与 `close_price` 同期方向**相反**的窗口占比 > 50% | 两者方向独立，反向约 50% |


### 方向定义

对每个滑窗，取序列末值 − 首值：

- `Δ > 0` → 方向 **+1（涨）**
- `Δ < 0` → 方向 **−1（跌）**
- `Δ = 0` → 方向 **0（持平）**

同向：`dir_x == dir_y`（含 0 == 0）；严格反向：双方均非 0 且 `dir_x == −dir_y`。

### 进入「全品种」阶段的判定门槛

- S = 3 时 `main~close` 同向率 ≥ 55%，且二项检验 p < 0.05
- S ∈ {2, 3, 4} 结论方向一致（同向率均 > 50%）
- 价格涨侧与跌侧同向率均明显高于偶然

> **欧线集运是全市场唯一异类**：散户方向与价格方向的同向率（54.6%）高于反向率（43.7%），即散户在欧线集运上反而是对的。欧线集运的定价完全由航运供需驱动，大单行为可能反映的是真实套保需求而非投机博弈，导致散户反向规律在此失效。

## 七、综合结论

### 7.1 H1（主力共振）：强烈成立，具有跨品种普遍性

在 S = 3 的主报告窗下：

- **45 / 55 个品种**（82%）通过「同向率 ≥ 55% 且 p < 0.05」门槛
- 全市场中位同向率 **66.1%**，均值 **63.9%**，均远超随机基线 50%
- Bootstrap 验证（2000 次置乱）：S = 3 时 37 个品种实测值从未被零假设分布覆盖（boot_p = 0），46 个品种 boot_p ≤ 0.05
- 结论随窗长 S ∈ {2, 3, 4} **单调增强**，无一品种方向逆转

**主力资金方向与同期价格方向的高度一致性是跨品种的普遍结构性规律，并非单品种偶然现象。**

### 7.2 H2（散户反向）：同样强烈成立，与 H1 完全对称

- S = 3 时全市场散户反向率中位数 **66.7%**，通过品种 45 / 55，与主力共振完全对称
- 主力做多→价格涨、散户做多→价格跌，是**同一市场微观结构的两个侧面**，相互印证

### 7.3 主力与散户极度分化，构成共振规律的微观基础

- 全市场 main~retail 反向率均值 **76.9%**（S = 3），说明主力与散户绝大多数时间方向相反
- 这意味着当主力集中做多时，对手盘主要来自散户；市场成交的这种结构分层，是主力方向能有效预测价格方向的根本原因

### 7.4 板块分化特征


| 类别             | 代表品种                             | 核心原因                    |
| -------------- | -------------------------------- | ----------------------- |
| **最强（均值约70%）** | 沪锡/沪铅/沪铝/沪铜/沪金/沪银/沪镍/氧化铝（有色金属全部） | 有色金属定价国际化、流动性好，主力资金定价主导 |
| **次强（均值约65%）** | 菜油/豆一/棕榈油/纯碱/PVC/棉花/低硫燃油/热卷/焦煤等  | 主力集中度高的大宗品种，信号稳健        |
| **中等（均值约62%）** | 铁矿石/螺纹钢/沪锌/甲醇/乙二醇/烧碱等            | 普遍通过，但信号略弱              |
| **偏弱（均值约58%）** | 燃油/鸡蛋/工业硅/碳酸锂等                   | 通过但接近边界，信号弱，须谨慎使用       |
| **失效（均值约51%）** | 上证/欧线集运/锰硅/花生/原木                 | 定价机制异类或大单结构不典型，建议排除     |


### 7.5 双侧稳健性验证

价格涨侧同向率均值 **63.1%**，跌侧 **66.3%**，两侧均显著高于 50%，排除了单边行情伪造规律的可能性。跌侧略强，主力方向在下跌行情中指向更集中。

### 7.6 下一步建议

1. **策略池确定**：以通过验证的 45 个品种为基础，排除上证、欧线集运、花生、原木、锰硅等信号弱品种，有效策略池约 **40～45 个品种**。
2. **优先回测顺序**：
  - 第一批：有色金属 8 个品种（信号最强，均值 69.5%）
  - 第二批：油脂油料、化工能化头部品种（菜油/豆一/棕榈油/纯碱/PVC/棉花）
  - 第三批：其余通过品种
3. **因子构建方向**：
  - 当前结论基于方向（+1/−1/0），可进一步引入 `|Δ main_force|` 作为信号置信度权重，过滤低强度窗口
  - 主力散户对立度（main~retail 反向率）可作为辅助过滤条件，优先选取对立度高的品种
4. **边缘品种处理**：多晶硅（p = 0.058）、红枣、苹果等 5 个边缘品种可以纳入候选，但须在策略层加入额外过滤条件或等待更多数据。
