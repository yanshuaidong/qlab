# 获取模型列表

> 来源：[https://api-docs.deepseek.com/zh-cn/api/list-models](https://api-docs.deepseek.com/zh-cn/api/list-models)

```
GET /models
```

列出可用的模型列表，并提供相关模型的基本信息。请前往[模型 & 价格](../快速开始/模型与价格.md)查看当前支持的模型列表
