# 上传文件

> 来源：[https://api-docs.deepseek.com/zh-cn/api/create-file](https://api-docs.deepseek.com/zh-cn/api/create-file)

```
POST /files
```

上传图片文件，之后可在对话补全请求中通过其 `file_id` 引用。

支持的格式：JPEG、PNG、GIF、WebP。格式由文件内容判断。详见 [Files API 指南](../指南/文件API.md)。
