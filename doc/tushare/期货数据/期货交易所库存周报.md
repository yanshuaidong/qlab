# 期货交易所库存周报

> **接口：** `fut_inv_weekly` · [官方文档](https://tushare.pro/document/2?doc_id=495)

### 接口介绍
接口：fut_inv_weekly
描述：获取上海期货交易所库存周报
限量：单次最大3000条，可根据代码或日期循环提取
积分：需要5000积分可以调取，具体请参阅[积分获取办法](https://tushare.pro/document/1?doc_id=13)

### 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| trade_date | str | N | 交易日期（YYYYMMDD） |
| ts_code | str | N | 期货代码 |
| start_date | str | N | 开始日期（YYYYMMDD） |
| end_date | str | N | 结束日期（YYYYMMDD） |
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |
### 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | 期货代码 |
| trade_date | str | Y | 交易日期（YYYYMMDD） |
| fut_name | str | Y | 品种名称 |
| exchange | str | Y | 交易所 |
| area | str | Y | 地区 |
| warehouse | str | Y | 仓库名称 |
| grade | str | Y | 品级/油种 |
| pre_total | float | Y | 上周库存小计 |
| pre_futures | float | Y | 上周库存期货 |
| cur_total | float | Y | 本周库存小计 |
| cur_futures | float | Y | 本周库存期货 |
| chg_total | float | Y | 库存增减小计 |
| chg_futures | float | Y | 库存增减期货 |
| pre_capacity | float | Y | 可用库容量上周 |
| cur_capacity | float | Y | 可用库容量本周 |
| chg_capacity | float | Y | 可用库容量增减 |
| unit | str | Y | 单位 |
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |
### 代码示例
```python
# 导入sdk包
import tushare as ts

# 配置凭据，如果已全局配置了，可以忽略。
ts.set_token('<--your-token-->')

# 获取接口实例
pro = ts.pro_api()

# 拉取接口(fut_inv_weekly)数据
#获取ZN的数据
df = pro.fut_inv_weekly(ts_code='ZN')
# 示例：获取20260911的数据
df = pro.fut_inv_weekly(trade_date="20260911",fields='fut_code, trade_date, fut_name, exchange, warehouse')
print(df)
```
