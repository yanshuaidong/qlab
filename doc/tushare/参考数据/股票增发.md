# 股票增发

> **接口：** `stk_seasoned` · [官方文档](https://tushare.pro/document/2?doc_id=494)

### 接口介绍
接口：stk_seasoned
描述：获取上市公司针对A股增发的明细，覆盖历次增发预案、全流程进程节点、发行核心参数、配售情况及募资费用等增发信息。
限量：单次最大3000条，可根据代码或日期循环提取
积分：需要2000积分可以调取，具体请参阅[积分获取办法](https://tushare.pro/document/1?doc_id=13)

### 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | N | TS股票代码 |
| ann_date | str | N | 公告日期（YYYYMMDD） |
| start_date | str | N | 开始日期（YYYYMMDD） |
| end_date | str | N | 结束日期（YYYYMMDD） |

|  |  |  |  |
|  |  |  |  |

### 代码示例
```python
# 导入sdk包
import tushare as ts

# 配置凭据，如果已全局配置了，可以忽略。
ts.set_token('<--your-token-->')

# 获取接口实例
pro = ts.pro_api()

# 拉取接口(stk_seasoned)数据

#获取20260910数据
df = pro.stk_seasoned(ann_date='20260910')

# 获取000001.SZ数据
df = pro.stk_seasoned(ts_code="000001.SZ")
print(df)
```
