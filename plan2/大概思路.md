## 七、综合结论

### 7.1 H1（主力共振）：强烈成立，具有跨品种普遍性

在 S = 3 的主报告窗下：
- **45 / 55 个品种**（82%）通过「同向率 ≥ 55% 且 p < 0.05」门槛
- 全市场中位同向率 **66.1%**，均值 **63.9%**，均远超随机基线 50%
- Bootstrap 验证（2000 次置乱）：S = 3 时 37 个品种实测值从未被零假设分布覆盖（boot_p = 0），46 个品种 boot_p ≤ 0.05
- 结论随窗长 S ∈ {2, 3, 4} **单调增强**，无一品种方向逆转

**主力资金方向与同期价格方向的高度一致性是跨品种的普遍结构性规律，并非单品种偶然现象。**

### 7.2 H2（散户反向）：同样强烈成立，与 H1 完全对称

- S = 3 时全市场散户反向率中位数 **66.7%**，通过品种 45 / 55，与主力共振完全对称
- 主力做多→价格涨、散户做多→价格跌，是**同一市场微观结构的两个侧面**，相互印证

### 7.3 主力与散户极度分化，构成共振规律的微观基础

- 全市场 main~retail 反向率均值 **76.9%**（S = 3），说明主力与散户绝大多数时间方向相反
- 这意味着当主力集中做多时，对手盘主要来自散户；市场成交的这种结构分层，是主力方向能有效预测价格方向的根本原因

### 7.4 板块分化特征

| 类别 | 代表品种 | 核心原因 |
|------|---------|---------|
| **最强（均值约70%）** | 沪锡/沪铅/沪铝/沪铜/沪金/沪银/沪镍/氧化铝（有色金属全部） | 有色金属定价国际化、流动性好，主力资金定价主导 |
| **次强（均值约65%）** | 菜油/豆一/棕榈油/纯碱/PVC/棉花/低硫燃油/热卷/焦煤等 | 主力集中度高的大宗品种，信号稳健 |
| **中等（均值约62%）** | 铁矿石/螺纹钢/沪锌/甲醇/乙二醇/烧碱等 | 普遍通过，但信号略弱 |
| **偏弱（均值约58%）** | 燃油/鸡蛋/工业硅/碳酸锂等 | 通过但接近边界，信号弱，须谨慎使用 |
| **失效（均值约51%）** | 上证/欧线集运/锰硅/花生/原木 | 定价机制异类或大单结构不典型，建议排除 |

### 7.5 双侧稳健性验证

价格涨侧同向率均值 **63.1%**，跌侧 **66.3%**，两侧均显著高于 50%，排除了单边行情伪造规律的可能性。跌侧略强，主力方向在下跌行情中指向更集中。
