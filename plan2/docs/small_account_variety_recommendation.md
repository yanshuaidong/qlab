# 小资金实盘品种池推荐

**适用资金**：约 3 万保证金  
**单品种保证金约束**：单手占用尽量不超过 1 万，超过或接近 1 万的品种不作为首选  
**策略口径**：沿用策略 2 的 A 通道，即 `main_force` 主驱动、`retail` 只做反向确认、严格 7 日开仓、3 日主力拐头离场  
**组合约束**：最多 3 个槽位、不同持仓不得属于同一板块、每槽约 1/3 资金、空槽位保留现金  

> 保证金会随交易所、期货公司、合约价格和风控要求变化，本文只做实盘选池约束。真正下单前，应以交易软件显示的单手保证金为最终准入条件。

---

## 一、为什么要重选池 A

原池 A 的 12 个品种是：

| 板块 | 原池 A 品种 |
| --- | --- |
| 有色金属 | 沪铜、沪铝、沪锌 |
| 贵金属 | 沪金 |
| 黑色系 | 铁矿石、焦煤 |
| 化工能化 | PTA、甲醇、橡胶 |
| 油脂油料 | 豆粕、棕榈油 |
| 农产品 | 玉米 |

从研究和回测角度看，这个池子证明了三件事：

1. A 通道有效，主力跟随是当前策略的主要收益来源。
2. 板块互斥有效，跨板块分散能降低集中暴露。
3. 3 槽机制有效，资金不需要为了满仓而接弱信号。

但从 3 万保证金的小账户角度看，原池 A 有一个明显问题：**部分品种虽然统计信号好，但单手保证金太重，实盘无法按 3 槽组合稳定执行。**

尤其是：

| 品种 | 处理建议 | 原因 |
| --- | --- | --- |
| 沪金 | 剔除 | 单手保证金远超小账户承受范围，且在回测贡献中为拖累项 |
| 沪铜 | 剔除 | 合约价值高，单手保证金通常远超 1 万 |
| 沪锌 | 降级观察 | 接近或超过 1 万，且回测贡献偏弱 |
| 铁矿石 | 降级观察 | 单手保证金容易接近或超过 1 万，波动也偏大 |
| 焦煤 | 降级观察 | 单品种表现强，但保证金和波动都不适合小账户作为常规槽位 |
| 橡胶 | 剔除/观察 | 单手保证金偏高，且在组合贡献中不是核心收益来源 |

所以新版池子的目标不是追求统计排名最高，而是追求：

- 单手保证金更适合 3 万账户；
- 仍然保留跨板块分散；
- 优先保留 A 通道回测中真实贡献更好的板块；
- 不把资金锁死在高保证金品种上。

## 二、小资金选池原则

### 2.1 硬门槛

1. **单手保证金优先低于 1 万**  
   超过 1 万的品种，不进入首选池。即使历史信号很好，也只能放入观察池。

2. **必须通过主力共振统计验证**  
   优先选择 `main~close` 同向率在 S=3 下显著通过的品种。

3. **保留板块互斥结构**  
   策略 2 已经证明，板块互斥不是拖累，而是提升交易质量的约束。

4. **优先 A 通道，不重启 B 通道**  
   当前回测显示 B 通道没有带来稳定增量，因此新版池子仍只跑 A 通道。

### 2.2 软排序

同样满足保证金门槛时，优先级按下面顺序：

1. 回测贡献靠前的板块：化工能化、油脂油料。
2. `main~close` 同向率较高、两侧涨跌都不偏科的品种。
3. 保证金更低、能让 3 槽组合更容易落地的品种。
4. 流动性和成交活跃度更好的主力合约。

## 四、实盘优先级：不要 12 个一起平均看

虽然池子保留 12 个品种，但对 3 万账户来说，实盘不应理解成“12 个都要交易”。策略本身最多只持有 3 个槽位，所以 12 个品种只是信号候选池。

### 4.1 第一优先级：最适合马上实盘观察

| 品种 | 板块 | 理由 |
| --- | --- | --- |
| PTA | 化工能化 | 组合贡献强，保证金低，流动性好 |
| 甲醇 | 化工能化 | 低保证金，适合小账户执行 |
| 纯碱 | 化工能化 | 统计和回测表现都较好 |
| 豆粕 | 油脂油料 | 保证金低，贡献稳定 |
| 棕榈油 | 油脂油料 | 贡献强，但需接受波动 |
| 菜粕 | 油脂油料 | 低保证金，高性价比 |
| 热卷 | 黑色系 | 替代焦煤/铁矿石的小账户黑色选择 |
| 沪铅 | 有色金属 | 替代沪金/沪铜的有色选择 |

这 8 个品种已经能覆盖 4 个主要板块，足够让 3 槽策略运转。若希望更稳，可以先只跑这 8 个，观察 1 到 2 个月后再扩到 12 个。

### 4.2 第二优先级：用于补充信号密度

| 品种 | 板块 | 使用方式 |
| --- | --- | --- |
| PVC | 化工能化 | 当 PTA/甲醇/纯碱信号不足时补充 |
| 菜油 | 油脂油料 | 油脂板块补充，但注意波动和保证金 |
| 棉花 | 农产品 | 用来保留农产品分散，不建议重仓依赖 |
| 纸浆 | 其他/纸浆 | 用来增加非传统板块暴露 |

## 六、实盘执行建议

### 6.1 账户层面

3 万保证金账户建议仍按策略 2 的 3 槽思路执行，但要把“每槽 1/3”理解成风险预算，而不是必须满仓：

| 状态 | 建议 |
| --- | --- |
| 0 槽 | 没有强信号就空仓，不硬做 |
| 1 槽 | 正常状态，单品种保证金尽量控制在 1 万以内 |
| 2 槽 | 可接受，但要确保两个品种不同板块 |
| 3 槽 | 只在三者保证金都较低且不同板块时启用 |

如果任一品种开仓后导致可用资金明显低于 30%，即使它在池内，也应跳过。这一点比统计排名更重要。

### 6.2 下单前检查

每次实盘开仓前检查三件事：

1. 交易软件显示的单手保证金是否低于 1 万。
2. 当前持仓是否已有同板块品种。
3. 开仓后是否仍保留足够可用资金应对浮亏和保证金上调。

### 6.3 不建议做的事

| 行为 | 原因 |
| --- | --- |
| 为了追求焦煤收益而强行交易焦煤 | 焦煤适合更大资金账户，不适合作为 3 万账户常规槽位 |
| 因为沪金统计强就交易沪金 | 保证金过高会破坏组合策略 |
| 同时持有多个化工或多个油脂品种 | 违反板块互斥，等于重复下注同一类风险 |
| 12 个品种静态等权长期持有 | 当前策略收益来自信号筛选，不来自静态摊平 |
| 满仓硬凑 3 个槽 | 回测已经证明，空槽位保留现金是策略的一部分 |

---

## 七、最终建议

对当前 3 万保证金的小账户，建议把池 A 从原来的：

> 沪铜、沪铝、沪锌、沪金、铁矿石、焦煤、PTA、甲醇、橡胶、豆粕、棕榈油、玉米

调整为：

> **PTA、甲醇、纯碱、PVC、豆粕、棕榈油、菜粕、菜油、热卷、沪铅、棉花、纸浆**

其中实盘先重点盯：

> **PTA、甲醇、纯碱、豆粕、棕榈油、菜粕、热卷、沪铅**

这个版本牺牲了一部分“理论信号最强品种”，但换来了更重要的东西：**能用 3 万账户真实执行、不会被单个高保证金品种拖死、仍然保留跨板块分散和 A 通道主力跟随优势。**
